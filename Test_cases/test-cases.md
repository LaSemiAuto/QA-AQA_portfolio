# Test Cases

## TC-001 — Успешная авторизация

**Предусловие:** Пользователь зарегистрирован.

**Тестовые данные:**
   Email: test@shop.com
   Password: 123456

**Шаги:**
1. Открыть страницу авторизации.
2. Ввести корректный email.
3. Ввести корректный password.
4. Нажать кнопку "Log in".

**Ожидаемый результат:** Пользователь успешно авторизован и перенаправлен на главную страницу по адресу: https://demowebshop.tricentis.com
   вместо кнопки "Register" появляется email пользователя.
