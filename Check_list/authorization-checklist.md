# Checklists

## Чек-лист проверки авторизации

- [ ] Авторизация с корректными учетными данными.
- [ ] Авторизация с неверным паролем.
- [ ] Авторизация с незарегистрированным email.
- [ ] Отправка пустой формы.
- [ ] Проверка формата email.
- [ ] Проверка отображения ошибки авторизации.
- [ ] Проверка показа и скрытия пароля.
- [ ] Проверка возможности выйти из аккаунта.
